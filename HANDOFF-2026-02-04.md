## Architecture Notes

### Key Packages

```
cmd/                    # Cobra commands
  init.go              # bz init
  version.go           # bz version (with --json)
  root.go              # Root command, global flags
  mod/                 # bz mod subcommands
    add.go, rm.go, list.go, info.go
    update.go, outdated.go, search.go, sync.go
  registry/            # bz registry subcommands
    ping.go

internal/
  cli/                 # CLI utilities
    options.go         # Global options (quiet, no-color)
  registry/            # Registry abstraction
    adapter.go         # go-bcr adapter (FromBCR)
    factory.go         # New(), NewWithOptions()
    http.go, file.go   # Legacy implementations
    search.go          # Fuzzy search
  version/             # Version comparison
    version.go         # Compare(), IsPrerelease(), LatestStable()
  module/              # MODULE.bazel parsing
  starlark/            # Starlark evaluation
  tui/                 # Bubbletea TUI (incomplete)
```

### go-bcr Integration

The `internal/registry/adapter.go` wraps go-bcr:

```go
// Create registry with caching
reg, _ := registry.NewWithOptions(
    "https://bcr.bazel.build",
    registry.WithCacheDir("/tmp/bz-cache"),
    registry.WithCacheTTL(time.Hour),
)

// Or wrap go-bcr directly
client := bcr.New(bcr.WithBaseURL(url))
reg := registry.FromBCR(client)
```

### Phase 3: Insights & Analysis

#### 3.1 `bz mod graph` (Medium)

Visualize dependency tree.

```bash
bz mod graph                 # ASCII tree
bz mod graph --format=dot    # Graphviz DOT
bz mod graph --format=mermaid
bz mod graph --depth=2
```

**Output example:**

```
my_module
├── rules_go@0.50.1
│   └── platforms@0.0.10
├── rules_python@0.35.0
│   ├── rules_cc@0.0.9
│   └── platforms@0.0.10
└── gazelle@0.38.0
    └── rules_go@0.50.1
```

**Implementation:**

- Parse MODULE.bazel for direct deps
- Fetch each dep's MODULE.bazel recursively
- Build graph, detect cycles
- Multiple output formatters
