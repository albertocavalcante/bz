### Air-Gap Configuration System

**TOML Configuration** (`~/.config/bz/config.toml` or `.bz.toml`):

```toml
[network]
mode = "prefer-offline" # online, prefer-offline, offline
registry = "https://bcr.bazel.build"
timeout = "30s"

[cache]
dir = "~/.cache/bz"
ttl = "24h"

[commands]
disabled = ["audit"] # disable specific commands
```

**Environment Variables**:

- `BZ_OFFLINE` - Enable offline mode
- `BZ_PREFER_OFFLINE` - Enable prefer-offline mode
- `BZ_REGISTRY` - Override registry URL
- `BZ_CACHE_DIR` - Override cache directory
- `BZ_DISABLE_COMMANDS` - Disable commands (comma-separated)

## Architecture Decisions

### TOML over INI for Configuration

- Native array support for `disabled` commands list
- Typed values (strings, bools, durations)
- Zero-dependency library (BurntSushi/toml)
- Industry standard for CLI tools

### Keep Cobra Framework

- Dynamic shell completion support is critical
- Well-tested, stable ecosystem
- Binary size (~8.6MB) acceptable for CLI tool

### NetworkAwareRegistry Pattern

- Wraps inner registry with network mode logic
- Three modes: online, prefer-offline, offline
- Helpful error messages with suggestions on cache miss

### SourceGetter Interface

- Optional interface (not part of main Registry)
- Type assertion pattern for optional capabilities
- Cleaner than concrete type checks

## Known Limitations

1. **OSV Ecosystem Mapping**: Bazel isn't a native OSV ecosystem. Module names are mapped to underlying ecosystems (rules_go → Go, rules_python → PyPI). Unmapped modules require `--ecosystem` flag.

2. **License Detection**: Depends on registry `source.json` having license field. Shows "Unknown" if not present.

3. **Cache Directory**: Currently uses `~/.cache/bz`. Not yet configurable via TOML (uses env var).
