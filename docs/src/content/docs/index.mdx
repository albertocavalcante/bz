## What is bz?

bz is a CLI tool for managing Bazel modules. It provides commands to search, inspect, and sync modules from various registries like the [Bazel Central Registry](https://registry.bazel.build).

**Key capability: Sync modules from any source to any destination.**

```bash
bz mod search rules_go   # Search for modules
bz mod show rules_go     # View module details
bz mod sync              # Sync modules to your registry
```

## Quick Example

Create a `bz.star` configuration file:

```starlark
# Define source and destination registries
bcr = registry.http("https://bcr.bazel.build")
mirror = registry.file("/path/to/mirror")

# Sync rules_go and rules_python to local mirror
sync.workflow(
    name = "mirror-essentials",
    origin = bcr,
    destination = mirror,
    modules = ["rules_go", "rules_python"],
    versions = sync.latest(count = 3),
)
```

Then run:

```bash
bz mod sync --workflow mirror-essentials
```

## Commands

| Command | Description |
|---------|-------------|
| `bz mod search <query>` | Search for modules by name |
| `bz mod show <module>` | Display module metadata and versions |
| `bz mod sync` | Sync modules according to workflow configuration |
