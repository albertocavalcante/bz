---
title: bz mod show
description: Display detailed module information
---

Display detailed information about a Bazel module, including available versions and metadata.

## Synopsis

```bash
bz mod show <module>[@version] [flags]
```

## Description

The `show` command retrieves and displays metadata for a specific module. Without a version specifier, it shows general module information and lists all versions. With a version specifier, it shows details for that specific version.

## Arguments

| Argument | Description |
|----------|-------------|
| `module` | Module name (e.g., `rules_go`) |
| `@version` | Optional version specifier (e.g., `@0.50.1`) |

## Flags

| Flag | Short | Description |
|------|-------|-------------|
| `--registry` | `-r` | Registry URL (default: BCR) |
| `--json` | | Output as JSON |
| `--versions` | `-V` | Show only version list |

## Examples

### Show Module Overview

```bash
bz mod show rules_go
```

Output:
```
Module: rules_go
Homepage: https://github.com/bazel-contrib/rules_go
Maintainers: bazel-contrib

Versions (15 total):
  0.50.1 (latest)
  0.50.0
  0.49.0
  0.48.1
  0.48.0
  ...

Yanked versions: 0.47.0
```

### Show Specific Version

```bash
bz mod show rules_go@0.50.1
```

Output:
```
Module: rules_go
Version: 0.50.1

MODULE.bazel:
  module(
      name = "rules_go",
      version = "0.50.1",
      compatibility_level = 0,
  )
  ...

Source:
  URL: https://github.com/bazel-contrib/rules_go/releases/download/v0.50.1/rules_go-v0.50.1.zip
  Integrity: sha256-abc123...
  Strip Prefix: rules_go-0.50.1
```

### JSON Output

```bash
bz mod show rules_go --json
```

Output:
```json
{
  "name": "rules_go",
  "versions": ["0.50.1", "0.50.0", "0.49.0"],
  "yanked_versions": {"0.47.0": "Security issue"},
  "homepage": "https://github.com/bazel-contrib/rules_go"
}
```

### List Only Versions

```bash
bz mod show rules_go --versions
```

Output:
```
0.50.1
0.50.0
0.49.0
0.48.1
0.48.0
```

### Custom Registry

```bash
bz mod show mymodule --registry https://registry.example.com
```
