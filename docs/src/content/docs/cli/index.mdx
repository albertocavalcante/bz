bz provides commands for searching, inspecting, and syncing Bazel modules.

## Global Flags

These flags are available for all commands:

| Flag | Description |
|------|-------------|
| `--help, -h` | Show help for the command |
| `--version, -v` | Show version information |
| `--verbose` | Enable verbose output |

## Quick Reference

```bash
# Search for modules
bz mod search <query>

# Show module details
bz mod show <module>
bz mod show <module>@<version>

# Sync modules
bz mod sync --workflow <name>
bz mod sync --workflow <name> --dry-run
bz mod sync --list
```

## Exit Codes

| Code | Description |
|------|-------------|
| 0 | Success |
| 1 | General error |
| 2 | Invalid arguments |

## Environment Variables

| Variable | Description |
|----------|-------------|
| `BZ_CONFIG` | Default config file path |
| `BZ_VERBOSE` | Enable verbose mode (`true`/`false`) |
| `BZ_REGISTRY` | Default registry URL |
