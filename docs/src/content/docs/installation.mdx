## Requirements

- Go 1.25 or later (for building from source)
- Git (for git-based registries)

## Install Methods

<Tabs>
  <TabItem label="Binary">
    Download a pre-built binary from the [latest release](https://github.com/albertocavalcante/bz/releases/latest), extract it, and move it to a directory in your PATH:

    ```bash
    # Example for Linux (amd64)
    tar -xzf bz-linux-amd64.tar.gz
    sudo mv bz /usr/local/bin/
    ```

    Binaries are available for Linux, macOS, and Windows on both amd64 and arm64.
  </TabItem>

  <TabItem label="Go Install">
    Install directly with Go (requires Go 1.25+):

    ```bash
    go install github.com/albertocavalcante/bz@latest
    ```

    Make sure `$GOPATH/bin` is in your PATH.
  </TabItem>

  <TabItem label="From Source">
    Clone and build from source:

    ```bash
    git clone https://github.com/albertocavalcante/bz.git
    cd bz
    go build -o bz .
    ```

    Move the binary to a location in your PATH:

    ```bash
    sudo mv bz /usr/local/bin/
    ```
  </TabItem>
</Tabs>

## Verify Installation

Check that bz is installed correctly:

```bash
bz --version
```

You should see the version number printed.

## Shell Completion

bz supports shell completion for bash, zsh, fish, and PowerShell.

<Tabs>
  <TabItem label="Bash">
    ```bash
    # Add to ~/.bashrc
    source <(bz completion bash)
    ```
  </TabItem>

  <TabItem label="Zsh">
    ```bash
    # Add to ~/.zshrc
    source <(bz completion zsh)
    ```
  </TabItem>

  <TabItem label="Fish">
    ```bash
    bz completion fish | source
    ```
  </TabItem>
</Tabs>
