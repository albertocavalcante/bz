## Requirements

- Go 1.26 or later (for building from source)
- Git (for git-based registries)

## Install Methods

Choose a published `v0.1.0-rc.N` from [GitHub Releases](https://github.com/albertocavalcante/bz/releases).

<Tabs>
  <TabItem label="Binary">
    Download the archive and its matching `.sha256` file from the same release. Verify the archive before extracting it and moving the binary to a directory in your PATH.

    ```bash
    # Example for Linux (amd64)
    sha256sum --check bz-linux-amd64.tar.gz.sha256 &&
      tar -xzf bz-linux-amd64.tar.gz &&
      mkdir -p ~/.local/bin &&
      mv bz ~/.local/bin/
    ```

    Make sure `~/.local/bin` is in your PATH.

    Binaries are available for Linux and macOS on amd64 and arm64, and for Windows on amd64.
  </TabItem>

  <TabItem label="Go Install">
    Install directly with Go using the exact release tag. For example, for `v0.1.0-rc.1`:

    ```bash
    go install github.com/albertocavalcante/bz@v0.1.0-rc.1
    ```

    Make sure `$GOPATH/bin` is in your PATH.
  </TabItem>

  <TabItem label="From Source">
    Clone and build from source:

    ```bash
    git clone https://github.com/albertocavalcante/bz.git
    cd bz
    go build -o bz .
    ```

    Move the binary to a location in your PATH, such as `~/.local/bin`:

    ```bash
    mkdir -p ~/.local/bin
    mv bz ~/.local/bin/
    ```
  </TabItem>
</Tabs>

## Verify Installation

Check that bz is installed correctly:

```bash
bz --version
```

You should see the version number printed.

## Shell Completion

bz supports shell completion for bash, zsh, fish, and PowerShell.

<Tabs>
  <TabItem label="Bash">
    ```bash
    # Add to ~/.bashrc
    source <(bz completion bash)
    ```
  </TabItem>

  <TabItem label="Zsh">
    ```bash
    # Add to ~/.zshrc
    source <(bz completion zsh)
    ```
  </TabItem>

  <TabItem label="Fish">
    ```bash
    bz completion fish | source
    ```
  </TabItem>
</Tabs>
